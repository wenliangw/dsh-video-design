# 业务：核心概念

## 1. 三阶层官方能力库（拍摄手法知识）

- **层1 词汇轴**：11 域 = 经典 7 轴内核（景别/机位角度/机位运动/构图/光线/色彩氛围/时间节奏，封闭枚举严格校验）+ 4 扩展域（声音配乐/画幅时长输出/VFX特效后期/人物动作表演，开放成长枚举，加词不动 schema）。
- **层2 手法卡片（第一公民）**：一张卡 = 名称 + 人话描述 + 轴值配方 + 情绪标签 + 示例 + provenance（官方/项目沉淀）。迭代单位是加卡；项目沉淀卡进 story wiki，人气可回迁官方。
- **层3 组合包**：预制多卡配方的新手入口（「紧绷悬疑开场 = 荷兰角 + 缓慢推近 + 冷色调」）。
- 选项从卡片抽样，参数永藏配方内。静态航运保证首日可用，项目生长保证越用越懂。

## 2. 记忆五层（story 级）+ 工作区底色

| 概念 | 职责 | 关键规则 |
|---|---|---|
| wiki | 故事认知：世界观、角色关系、约束 + 项目沉淀手法 | 官方手法卡不在 wiki（航运包内） |
| tastes | story 级审美 | 工作区底色在前，story 覆盖在后 |
| decisions | 创作决策（决策链 caused_by/supersedes） | 反复踩坑升级为生成器约束决策 |
| material | 人物/场景/道具档案 | **共识门控**：设计讨论→提案→用户确认才落盘；按实体建目录（card.md + card.svg + refs/ 参照原件） |
| corrections | 纠错（记因果不记结果） | story 级（叙事坑）+ 工作区级（生成器通用坑） |

## 3. 选项化共同设计

普通用户无法表述专业镜头需求。Agent 从能力库抽样 2~4 个正交差异的流派卡片选项，用户「选 A 没选 B」= 零成本品味信号回流 tastes。支持「部分锁定 + 局部再选项化」。taste 高置信轴直接预填，只问真的不确定——信号不浑浊。

## 4. 提示词两层标准化

- 标准层（我们的话语）：固定子句顺序 `[时间窗] 主体与动作 | 镜头运动 | 构图 | 光线 | 氛围 | 声音`，可倒解析回 11 域 JSON。
- 厂商层（翻译稿）：adapter 转译为叙述流单一字符串（单窗合句 / 多窗「前 3 秒…随后…」）。
- 每 shot 三份记录：shot（标准 JSON）/ vendor_prompt（厂商全文快照）/ meta（model、duration、quality、task_id、attempts[]）——生成前 dry-run、生成后任意时刻可回查。

## 5. SVG 预览「一图两用」

- 三用途：shot 构图预览（确认卡头图，杀手用途）/ material 设定卡配图 / 分镜故事板（v2）。
- 参照图：用户上传素材图 → Agent read_image 多模态解读 → 在其基础上优化出 SVG 稿 + card.md，确认卡原图 vs SVG 对照；原件归档 refs/。
- 喂生成器：sharp/resvg 栅格化 PNG → 默认 reference_mode（参考素材弱约束，2.0/2.5）→ 首帧强约束留实验位；渲染失败降级纯 T2V。SVG 不承诺照片级（照片级增强归 v2 文生图）。

## 6. 纠错学习闭环

出片后用户开口（脸崩了/节奏不对——不主动打扰）→ Agent 归因（prompt 结构？多主体？历史坑命中？）→ 与用户确认因果 → corrections 落盘 → 重拍时转成确认卡「约束区」默认项 → 反复踩坑升级为生成器约束决策进决策链。

# dsh-video-design

dsh 视频生成插件 —— 通过自然语言 + mesync 记忆理念，设计专业镜头语言，并驱动 seeddance / 小云雀视频生成。

## 理念

- **自然语言 → 专业镜头语言**：把「很燃」「主角登场」这类模糊需求，编译成结构化、可校验、可积累的镜头语言。
- **mesync 记忆**：认知（wiki）/ 决策（decisions）/ 品味（tastes）+ 纠错（corrections），越用越懂用户品味，从错误中学习原因。
- **选项化共同设计**：Agent 穷举多种专业拍法，由用户选择，选择即品味信号。

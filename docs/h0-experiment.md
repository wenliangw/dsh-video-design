# H0 实验设计：生成器能力摸底

> 状态：**已开跑**。首个数据点 greet-r1（2.5 档、5s、四拍动线串）用户验收：没动线、没人物特点。
> 归因见「已采数据」；据此 Phase 1 格网升级为「动线轴逐档 + 恒定人物定卡」。

## 目的

画一张「这个生成器现在**什么可控、什么不可控**」的边界图。它是一切后续实验的归因地基：
H1（句式效应 A/B）、H2（结构化句型对照）如果没有这张图，失败的镜头就分不清
「是写法不行还是模型档不行」——v1 的 S006 就是三变量纠缠、靠猜归因的教训。

## 铁律

1. **纯提示词**：只写场景事实描述，不出现任何拍摄手法词汇（景别/机位/运镜/打光话术）。
2. **每格同 prompt 重复 3 次**：视频生成有随机性，3 次才能区分「运气」与「能力」。
3. **变量最小**：一轮只动一根轴；换场景/换档/换时长都是下一轮的事。
4. **写完判据再跑**：判定标准先定死，不事后改（下表）。

## 常量卡（Phase 1 全格网冻结，不许动）

- **场景**：校园大门（早晨）。— 与 greet-r1 同场景，保证与已采数据的可比性。
- **人物定卡**（每格 prompt 一字不改地嵌入）：
  `梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生`
  —— 人物没有特点多半是 prompt 没给素材；定卡给足「发型/外衣/下装/背包」四件具体特征，
  让「人物像不像」成为可判的变量，且全轴共用同一人物，「动线」是唯一在变的轴。

## Phase 1：动线轴逐档（每个格子 3 次，5s 不变）

| 格 | 拍数 | 测什么 | 提示词（纯文本，一字不改） |
|---|---|---|---|
| **A1 静立基线** | 0 | 无动线时人物定卡能否被忠实渲染（若 A1 都翻车，问题在基础渲染不在动线） | `校园早晨，一位梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生，静静站在校园大门前，双手插在衣兜里，微风吹起她的发梢。写实风格，自然光线。` |
| **A2 局部动作** | 1 | 原地小动作（抬臂挥手）能否兑现 | `校园早晨，一位梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生，站在校园大门前，抬起一只手，微笑着向迎面方向挥了挥。写实风格，自然光线。` |
| **A3 空间位移** | 1 | 位置移动（门外→门内）能否兑现 | `校园早晨，一位梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生，从校园大门外慢慢走进校园，脚步平稳。写实风格，自然光线。` |
| **A4 位移+交互** | 2 | greet-r1 复跑：拍数减半后能否保住两拍 | `校园早晨，一位梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生，从校园大门外走进来，停下脚步，微笑着向迎面走来的同学挥了挥手。写实风格，自然光线。` |
| **B1 持续位移+道具** | 1 | 推车行进（v1 四事故同源：比例/车留原地/位置漂移） | `晴天傍晚，一位梳高马尾、穿米白色羽绒服和深蓝牛仔裤、背浅灰色双肩包的年轻女大学生，推着一辆银灰色旧自行车，沿校园林荫道慢慢向远处走，夕阳暖光把她的影子投在地面上。写实风格。` |

**模型档**：用用户配置的默认档（当前 2.5 高保真档）。按「质量优先」决策先测高保真，
低档当 Phase 2 的对照变量再用。**时长 5s 钉死**；「多拍塞 5s 掉拍」只是假设，
留待 Phase 2 用 10s 对照验证——不动线轴这一轮的变量。

## 判定标准（写死，不事后改）

每格 3 次验收，每片先勾「拍执行清单」（见验收标签），再判：

| 结果 | 结论 | 边界图记录 |
|---|---|---|
| 3/3 可用 | 该格「稳」 | 此配置下生成器稳定兑现 |
| 2/3 可用 | 「边缘可控」 | 需要重看失败样本找条件差异 |
| ≤1/3 可用 | 「不可控」 | 该维度标记为边界外，后面的实验不得把责任再推给提示词 |

## 验收标签（每片回填 verdict / verdictNote）

- `verdict` = `可用` / `不可用`
- `verdictNote` = 一句事实 + **拍执行清单**（先勾后评，防止凭印象）：
  - A1：保持静止、无漂移 □；人物特征与定卡一致 □
  - A2：挥手动作出现且无畸变 □；人物不动位 □
  - A3：人从门外位移到门内 □；位移连续无瞬移 □
  - A4：位移拍 □ 停下拍 □ 挥手拍 □（≥2 拍算执行到位）
  - B1：人车同行推进 □；车不消失/不留在原地 □；身体比例正常 □
- 失败类别标签沿用 v1 四事故归因：
  - **物理**：身体比例失调 / 接触不实（脚飘、影离）/ 道具恒存断裂
  - **空间**：方向反转 / 位置漂移 / 道路×动线违和
  - **内容**：漏元素 / 多元素 / 主体错
  - **风格**：与描述气质不符

## Phase 2：入门条件与变量轮换（动线轴全过才进，避免烧钱）

- 时长对照：同格 5s vs 10s（验证「拍数超载」假设）
- 模型档对照：高保真 vs 低档（同 prompt 同参数）
- 场景多样性轴：换 1-2 个新场景按住动线档重测三步（钉「动线能力是否场景无关」）

## 操作节奏

1. `shot_gen`（dry_run=true）→ 我贴请求体全文 + 目标地址给你过目；
2. 你点头 → 同参数去 dry_run 真提交（label 如 `h0-a1-r1`）；
3. `shot_task` 轮询取片 → 你看片给验收（拍执行清单打勾）→ 回填 verdict 字段；
4. 一格 3 次收齐 → 按判定表出结论 → 汇报边界图更新。

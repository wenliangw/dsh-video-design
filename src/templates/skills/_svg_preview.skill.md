# SVG 绘制规范（v1 简版）— 构图示意 / 素材设定卡

SVG 是本插件「给人确认」的视觉语言：确认卡头图（构图预览）与 material 设定卡。示意不追求照片级——画对关系，不画对纹理。

## 画布约定

- 默认画布 640×360（16:9 对齐出片画幅），material 设定卡 480×480 或随内容。
- 网格背景：淡灰 #e4e4e7，主体色高饱和（一眼看清）。

## 构图示意符号（确认卡头图）

| 元素 | 画法 |
|---|---|
| 取景框 | 画布即画面；景别用主体占据画幅比例表达（CU≈头部占 1/2 高） |
| 主体 | 简洁人形剪影（头圆+肩线）代表人物；矩形代表物体 |
| 运动 | 带箭头虚线（dolly-in 指向主体、orbit 画圆弧箭头、whip-pan 画横甩箭头） |
| 光线 | 光源位置画小圆 + 放射短线；暖光 #f59e0b、冷光 #60a5fa、霓虹 #e879f9 |
| 构图 | 三分线淡虚线；对角/对称/留白用辅助线示意 |
| 地面 | 一条横线 + 阴影椭圆代表站位 |

## 人物设定卡

- 结构：正面站姿剪影 + 服饰色块分层（发色/上装/下装/鞋子）+ 关键配饰放大节点。
- 配色提取 = 从参照图（`.story/material/<实体>/refs/`）取 3-5 个主色导出成色块备注。
- 文字标注用 `font-family="sans-serif"`，保持清晰可读。

## 规范红线

- 不画脸（只用剪影/色块），除非角色五官本身就是设定卖点。
- 每张图一个核心信息：构图示意表达「镜头语言」，设定卡表达「这个角色的视觉锚」。
- 输出后一律 `svg_render` 转 PNG 给人看（部分界面不支持内嵌 SVG）；SVG 源文件一并落盘（可 diff、可再改）。

> 参照图流程：用户传图 → `read_image` 解读（配色/结构/姿态）→ 在其基础上出「优化稿」（规范化符号、修正构图）→ 确认卡原图 vs SVG 对照。

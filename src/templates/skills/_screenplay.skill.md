# screenplay 心法 — 故事结构/单集故事 → 剧本（beat 序列）

输入：`.story/story-structure.md` 的分集计划（或用户直接给的单集故事/单片需求）。
输出：`EP00N/script.md`。**剧本写「发生什么」，不写「怎么拍」**——镜头语言是 `_script2shot.skill.md` 的翻译（与标准层/厂商层分离同一条纪律）。

## 第一步：分集（从故事结构进入时）

- 每集 = **可独立成立的推进单元 + 结尾钩子**；单元边界优先落在事件弧的升级格上。
- 上一集结尾的钩子，本集 hook 必须兑现或明确悬置（钩子不回收 = 剧本事故）。
- 每集容量 = 结构里用户拍板的时长预算（单镜 2–30s，一集镜头数 × 时长 = 预算）。

## 第二步：本集四拍

hook（勾住：开场 3 秒内立住冲突）→ 铺垫（建立筹码）→ 转折（升级/反转）→ 收束（本集闭环 + 钩子留痕）。

## 第三步：beat 化（四拍 → beat 表）

每拍拆 1..N 个 beat。beat 字段：

| 字段 | 说明 |
|---|---|
| 编号 | B01/B02…（拍内递增） |
| 场景 | 谁 + 在哪 + 干什么（不含镜头词；场景时间信息也写在这里） |
| 对白/旁白 | 原文台词，或「（旁白）…」——**去向见下方「对白的诚实去向」** |
| 声音设计 | 环境声/音乐/静默（v1 仅记谱，见下） |
| 情绪目标 | 观众此刻该感到什么（一个词起步，动词化优先） |
| 预估时长 | 2–30s 对齐单镜约束；拟拆 N 镜的 beat 需 ≥ N×2s（单镜最短 2s——时长不够就合并 beat，别把难题推给拆镜层） |

### 对白的诚实去向（v1 出片无声）

sound 轴在 v1 仅**记谱**（doctrine 08-sound：出片为无声成片，generate_audio 尚未接线）。beat 里写对白是写戏、是创作资产——但去向必须诚实标注，三条：

1. 需要唇动/表情张力的台词 → 「场景」栏加 performance 倾向（**画面无声表演**，模型演不发声）。
2. 旁白 → 改写成**画面意象**写进「场景」栏（旁白是画面的叙事代理，不是声音）。
3. 纯台词 → 保留原文在字段里，标注「v2 语音/字幕预留」。

底线：把对白当「要求演员表演什么」的注记写，不向用户承诺成片发出声音。

## 不可拍文字转化（小说素材在此层处理）

- 内心独白 → 旁白（voiceover，按上方去向 2 画面化），或删（画面已表达）。
- 情绪/氛围 → 空间意象（环境隐喻：雨天、空椅、半杯水）。
- 需要演员表演张力 → beat 的「场景」栏标 performance 倾向，轴值留给 `_script2shot`。

## 落盘与共识

- `EP00N/script.md` front-matter：`title / episode / format / mood / target-duration`；正文 = 四拍小节 + beat 表。
- 剧本初稿给用户确认（改对白/节奏/情绪），确认后才进入拆镜层；确认后更新 `.story/overview.md` 的 EP 进度区。

## 回流钩子

用户对剧本的每次修正都是信号：对白风格/节奏密度/情绪落点 = 叙事口味 → `.story/tastes/`；「故事→beat」的转化坑（时长爆表、钩子断链）→ `.story/corrections/`（「改这里→检查哪里」形态）。

## 红线

- beat 的「场景」栏出现镜头词（特写/仰拍/推镜）即越界——那是 `_script2shot` 的事。
- 单集信息密度：30s×N 的预算只讲一件事（可有多层冲突，但只有一个落点）。
- 不承诺语音：剧本可以有台词，成片承诺里没有声音（v1）。

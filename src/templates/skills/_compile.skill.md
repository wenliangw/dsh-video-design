# compile 心法 — 自然语言 → 标准镜头语言（收敛协议）

把用户模糊需求编译为可校验镜头语言。**目标是采集真实偏好的信号，不是让用户填满 11 域。**

## 判定具体度

- **具体输入**（含量化镜头语：「45°仰拍+甩镜转场」）→ 直编译 + 确认卡，跳过选项化。
- 无论具体/模糊，**先立基础面卡**（读 `.dvd/doctrine/foundation.md`）：景→人→交互→动线必须成卡才进转译——景先立（三锚+机位+时辰）、人后入（身份/比例/站位）、交互对齐（接触/遮挡/尺度/恒存）、动线可选；基础面是必填地基，不参与选项化。
- **持有物纪律**：凡 subject/事件中人物携带的随身道具（车/包/伞…），一律在 `characters[].props` 声明「名（状态）」；事件序列的每个动作段必须重述持有状态（如「并肩走远（A 推着车）」）。持有物外观锚走 material 道具档案（共识门控）。
- **subject 与 foundation 职责分离**：subject 只写「谁干什么」的叙事 + 服化短语（主体词固定表逐字复用）；世界信息（时刻/光线/道路走向/相机方位/轴线/动线位置/朝向/事件序列）全部交给 foundation，**两层禁止重复描述**——重复内容在厂商层超出插件裁剪上限（默认 500 字 = 官方建议值）时按「；」边界被整体砍尾，先丢的是 foundation 冗余副本（见 `_seedance.skill.md` 转译次序）。
- **模糊输入**（「要炸」「很温柔」）→ 选项化流程。

## 记忆省问

动手前先召回（`video_recall` + 读 `.story/tastes/` + `.story/corrections/`）：

- taste 高置信的轴直接预填，并标注来源（默认来自品味 —— 用户改掉它 = 一次有效负信号）。
- corrections 历史坑转成确认卡「约束区」默认项（生成即带提醒）。

## 分层选项 ≤ 3 轮

每轮 2-4 个选项；来源 = 手法卡片 / 组合包（工作区 `.dvd/doctrine/cards`、`.dvd/doctrine/presets`，随包航运的官方能力库副本——Agent 可直接 read），选项差异必须**正交**（不同流派），不做同流派的参数微调。

- 轮1 感觉层：情绪标签 → 流派卡片组（如「燃」→ orbit-reveal / low-angle-hero / whip-pan-cut / slow-push-in）。
- 轮2 手法层：流派内仍有分叉才问（组合包选择或卡片换配）。
- 轮3 补缺层：公开面没覆盖的隐藏域（sound/vfx/performance）有缺口才问。

用户选 A 没选 B = 一条零成本品味信号 → 落 `.story/tastes/`（或 `video_remember` 关联信号）。

## 确认卡（一屏读完）

出卡必备：

1. **SVG 构图预览图**（`svg_render`）——取景框/主体位置/运动箭头/光线方向示意。
2. **基础面卡**——景→人→交互→动线（shot.foundation 必填面，先于 11 域清单展示；景先立、方向词必须落进几何，规范见 `.dvd/doctrine/foundation.md`）。
3. **11 域取值清单**——预填值标注来源（品味/wiki/默认）。
4. **素材登记区**——新角色/场景/道具：提案设定 → 用户勾选确认才落 `.story/material/`（共识门控）。
5. **约束区**——corrections 历史坑默认项，用户可见可删。
6. **成本预估**——`generate_shot` dry_run 给出积分预估。

## 指哪改哪

单域重选不动全局。用户说「换机位」「色调暖一点」，只重算该轴，其余域与已确认内容不变。

## 出片后

用户对成片的任何不满都是纠错闭环入口：归因 → 与用户确认因果 → 落 `.story/corrections/`（记为什么错，不记错了什么）。

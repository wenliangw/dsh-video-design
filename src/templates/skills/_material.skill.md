# 素材档案心法 — 共识门控（material 的产生需要用户确认）

## 门控流程（不可跳步）

1. **提案**：在确认卡的「素材登记区」提出实体（角色/场景/道具），附 SVG 优化稿 + 设定要点（视觉锚：主色/服饰/道具特征）。
2. **共识**：用户确认（勾选/点头/改后再确认）。
3. **落盘**：`.story/material/<characters|scenes|props>/<实体>/{card.md, card.svg, refs/}`——card.md 记视觉锚与出处，refs/ 保留参照原件。
4. **引用**：出片 prompt 引用视觉锚，保证跨镜头一致性。

## 参照图流程

用户传图 → `read_image` 多模态解读（配色/结构/姿态）→ 在用户原图基础上出 **SVG 优化稿** + card.md（确认卡里原图与优化稿对照展示）→ 确认后 refs/ 归档原图。

## 红线

- 未确认的实体**永不**落 material（宁可多问一遍）。
- material 是「已共识的财产清单」，不是实验田——实验设定放 wiki「待确认」区。
- SVG 是规范化示意，不承诺照片级；照片级增强归 v2 文生图。

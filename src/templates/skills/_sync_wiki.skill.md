# wiki 同步心法 — 故事认知与项目沉淀手法

`.story/wiki/` 记两类事：「故事是什么」+「我们在手法上的验证所得」。**只记定稿，不记流水。**

## 何时记

- 世界观/人物/冲突有**新定稿**（含用户改设定后再共识）→ `worldview.md` / `characters.md`。
- 某官方卡在此故事**验证有效**（出片成功且用户认可）→ `techniques.md`：官方卡 + 本故事用法差异（换配了什么、适配了什么故事情绪）+ 何时会再用。
- 组合被本故事反复使用或用户点名偏好 → 写成**项目手法卡**（结构对齐官方卡：轴值配方 + 情绪标签 + provenance: project）；够稳定后可回迁官方库。

## 怎么记

- 条目主干：一句话事实 + 一句为什么。禁止过程复述。
- **共识门控**：都要用户确认过才写死；未确认的事实标注「待确认」留在对应区块顶部。
- 记完同步 `.story/overview.md`（速览总入口——video_view 与注入投影只读它）相应区块，三行内。

## 不记什么

- 官方卡的通用写法（已经在插件 doctrine 里，不重复）。
- 用户没说过的背景设定。
- 一次性的镜头配置（那是 `EP00N/shots/S00n.json` 三份记录的事）。

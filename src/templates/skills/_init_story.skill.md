# 首次故事初始化心法 — 建档：探索 → .story/overview.md + wiki 出生

`video_init` 建好骨架后，故事记忆是空的。第一条正经工作不是开拍，是先给故事「建档」。

## 建档三步（不编造，宁空勿假）

1. **世界观与人物**：从用户描述/剧本/素材提取——时代、地点、主配角、核心冲突、既有素材资产。能明确的写进 `.story/wiki/worldview.md`、`characters.md`；不确定的**不留白装懂**，写进 overview 的「待确认」清单。
2. **风格初筛**：首轮选卡/问句就是第一批品味信号 → `.story/tastes/overview.md`（详见 `_sync_taste.skill.md`）。
3. **手法债登记**：用户提出的非常规拍法/自己的点子，先记 `.story/wiki/techniques.md` 的「待验证」区，验证过再转正。

## 更新 `.story/overview.md`（唯一注入入口）

一句话故事 / 卡司速览 / 进度（EP·shots）/ 当前约束（预算、禁忌、画幅）/ 待确认清单——**一分钟能读完**，越短越强。

## 红线

- 没确认的世界观设定不进 wiki 正文（进「待确认」区）。
- 空白故事不硬写满——宁留空等第一次真实创作信息，也不脑补占位。

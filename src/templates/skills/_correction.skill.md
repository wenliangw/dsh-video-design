# 纠错心法 — 因果清单（行为 → 关联检查）

## 判断

需要防止将来相同/类似行为漏处理的经验 = 纠错（**不是品味**，不进 tastes/）：按行为分类落 `.story/corrections/<分类>.md`（一类一文件，防单文件膨胀）。

## 形态

条目主干是「改这里 → 必须检查哪里」，语言简、清单式；允许一行「为什么」做锚。错误本身（时间、经过）**不记录**——出发点不是复盘，是防漏。

## 触发

- 用户指出错误、故障定位后 → 顺手落/更新一条。
- 出片前：任务涉及高危组合（多主体+大范围运动、新卡首试、长镜头、参照图模式首用）→ 先读 corrections 对应分类对照检查，把坑转进确认卡「约束区」。

## 闭环

- 同一坑反复踩 → 升维 `video_remember` 记一条生成器约束决策（与 corrections 互链）。
- 回看：成片需复现手法时，按分类读 corrections 即可携带全部避坑清单。

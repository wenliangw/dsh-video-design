# wiki 记忆规则 — 判定标准与文档结构

本文件定义 `.story/wiki/` 的文档结构和「什么能进 wiki」的判定规范（怎么记见 `_sync_wiki.skill.md`）。

## 文档结构

```
.story/
├── overview.md          # 故事速览入口（唯一读取方：video_view 与 Story Context 投影——一分钟读完）
└── wiki/
    ├── worldview.md     # 世界观定稿（时代/地理/力量体系/核心冲突）
    ├── characters.md    # 角色定稿（外形锚/性格/关系/出场）
    ├── techniques.md    # 手法验证所得（官方卡验证记录 + 项目手法卡）
    └── （按需新增，分类自定）
```

## 判定：什么能记

- **只记定稿**：经用户确认的世界观/人物/手法结论。未确认的事实标注「待确认」放对应文档顶部，不冒充定稿。
- **手法验证所得**：官方卡在本故事出片成功且用户认可 → techniques.md（官方卡名 + 用法差异 + 何时再用）；反复使用或用户点名的组合 → 项目手法卡（结构对齐官方卡 + provenance: project）。

## 判定：什么不记

- 官方卡的通用写法（doctrine 已有，不重复）。
- 用户没说过的背景设定（不替用户编世界观）。
- 一次性镜头配置（那是 `EP00N/shots/S00n.json` 的事）。

## 更新规范

- **增量更新**：只更新发生变化的部分，不重写整个 wiki；定稿变更补记新版本并可选划旧版删除线。
- 每次更新同步 `.story/overview.md`（速览总入口，明确路径）中的对应摘要；wiki 内不再单独维护 overview（避免写进无人读的死档）。
- 语言中文、Markdown 结构清晰。

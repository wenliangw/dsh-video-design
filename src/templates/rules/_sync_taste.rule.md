# 品味记忆规则 — 判定门槛与层级规范

本文件定义「什么算品味、记在哪层」的判定规范（怎么记见 `_sync_taste.skill.md`）。

## 判定：什么算品味

**品味 = 「将来做类似创作，用户会不会希望保持一致」。** 与 wiki/decision 判据不互斥——一条信息同时属于多块时，各记各的，不因「记了 A」跳过 B。

## 判定门槛（高置信才落盘）

- 反复出现（跨镜头/跨场景/≥2 次）或用户明确表态（「我一直喜欢…」「不要那种…」）。
- 重要选择：分层选项里用户选 A 放弃 B、确认卡指哪改哪。
- **红线**：只记用户真实表达过的，不脑补「他应该喜欢」；一次交互顺手记十条 = 噪音。

## 层级规范

1. **故事层** `.story/tastes/<分类>.md`（分类自定：pacing/lighting/composition/characters/narrative…）+ `overview.md` 速览。
2. **工作区层** `.dvd/tastes/<分类>.md`：同一品味在 **≥2 个故事重复**（或用户明说「我一般就那样」）才升维为工作区底色；升维后同步维护 `.dvd/tastes/overview.md`（Story Context 注入读取它）。

## 漂移规范

- 新信号推翻旧品味 → 旧条目**划删除线** + 标 `→ 已漂移：见新条目`；不删历史（漂移本身就是记忆）。

## 与纠错剥离

- 纠错是「行为防漏清单」（改这里→检查哪里），不是审美偏好——**不进 tastes/**，进 `.story/corrections/`。

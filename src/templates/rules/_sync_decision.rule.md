# 决策记忆规则 — 判定标准与因果链规范

本文件定义「什么算决策、怎么连链」。字段形由 `video_remember` 工具 schema 机器约束，本规则定「意」（怎么记见 `_sync_decision.skill.md`）。

## 判定：什么算决策

- **真实取舍**：用户在多个拍法/方案间选择，或明确否掉某方案。
- **否定重共识**：用户否定旧做法并达成新共识（最强信号）。
- **规律升维**：纠错背后挖出「以后一律这么做」的规律。
- 显式要求：「记住这个/以后都这样」。

## 判定：什么不算

- 过程流水、候选 prompt 草稿、一次性镜头配置。
- 用户随口一提、未形成取舍的意向。
- **宁缺毋滥**：不确定就不记。

## 因果链规范

- `supersedes`：新决策**取代/修改**旧决策 → 新节点指向旧节点 id，且把旧决策 outcome 更新为 `refined` 或 `reverted`。
- `caused_by`：新共识**因**旧决策（或其暴露的问题）而生 → 填前因 id。
- 语义不同、不必强凑：只有关系明确才填。同坑再犯 = 场景差异 = 新节点，不是旧节点「加深印象」。

## 联动义务

- `taste_signals`（决策→品味的指针）填了**必须配套落盘** `.story/tastes/`（或升维 `.dvd/tastes/`）——只填字段不落盘是「记了半层」。
- `scopes`：分类路径软关联（`tastes/…`、`wiki/…`、`seeddance/…`），缩小召回范围，改名失效无妨。

## 查询时机

- 出片/设计**前**先 `video_recall`（scope/query 过滤）带历史再决策，不凭空拍板。

# 素材记忆规则 — 共识门控与档案规范

本文件定义 material 的共识判定与档案结构规范（流程步骤见 `_material.skill.md`）。

## 共识判定：什么算「确认」

- 用户明确同意、点头、或**改后确认**（用户改 CV 后落盘的是改后版）。
- 勾选确认卡「素材登记区」的实体。
- **沉默 ≠ 确认**：用户没表态前，提案永远只停在确认卡里。

## 未确认实体的去向（硬规则）

- 未确认实体**永不落** `.story/material/`，宁可多问一遍。
- 实验性设定可以在 `.story/wiki/` 对应文档「待确认」区暂存——material 是「已共识的财产清单」，不是实验田。

## 档案结构

```
.story/material/<characters|scenes|props>/<实体>/   # 类型三选（新增类型与用户对齐）
├── card.md      # 视觉锚（主色/服饰/道具/姿态特征）+ 出处 + 确认时间
├── card.svg     # SVG 优化稿（规范化示意，非照片级承诺）
└── refs/        # 用户参照原件归档
```

- 实体目录名：小写英文 slug 或中文名，稳定后可被出片 prompt 引用。

## 更新规则

- 设定变更必须**重新共识**（用户确认）后才改 card；修改前把旧版本留痕到 `refs/`。
- 出片引用视觉锚，保证跨镜头一致性；card 只能来自共识，不能现场脑补。

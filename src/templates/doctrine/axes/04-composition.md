# 构图

画面内部的组织。三分法打底，其余构图对情绪有直接签名（对角线=张力，留白=孤独）。

- 或与「框中框/前景层次」组合，是营造「窥视/偷拍」感的捷径。
- 生成 prompt 里构图比光线更容易被模型遗漏，adapter 转译时构图子句放前面。

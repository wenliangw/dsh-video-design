# 景别

取景的范围，决定观众看什么。越近越情绪化（细节、表情），越远越叙事化（环境、关系）。

- 选项化时先定「观众离主体多远」，再谈氛围。
- 与机位运动组合：全景 + 环绕 = 揭示感；特写 + 推近 = 压迫感。
- 情绪检索示例：燃 → LS/FS；温柔 → MCU/MS；悬疑 → CU/ECU。

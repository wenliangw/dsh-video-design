# 画幅·时长·输出

展示端决定画幅。时长（秒数）由 compile 从时间与节奏轴裁出，映射 adapter 的 duration 参数（2–30s）。

- 竖屏 9:16 优先保证主体居中（裁切风险低）。
- 宽银幕 21:9 + 史诗管弦 = 电影感顶配。
- 分辨率默认 720p（成本/质量平衡），大片镜头再上 1080p。
